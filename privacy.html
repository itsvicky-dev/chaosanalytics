Privacy Policy

Last updated: 28 October 2026

ChaosAnalytics ("the app") is a personal analytics tool operated by the owner of the ChaosKannamma YouTube channel and Instagram account. It is used only by that owner, on their own computer.

Data the app accesses

  • YouTube (Google OAuth scopes youtube.readonly and yt-analytics.readonly): the owner's own channel and video metadata, public statistics, and YouTube Analytics / Reporting data (views, watch time, retention, subscribers, traffic sources, impressions, aggregated audience demographics and geography).
  • Instagram (permissions instagram_business_basic and instagram_business_manage_insights): the owner's own profile, media and insights.
  • Public data: public YouTube channel statistics of a few comparable creators, Steam player counts and Wikipedia pageview counts.

Access is read-only. The app never uploads, edits, comments on or deletes any content.

How the data is used

Solely to show the owner analytics about their own content, rank games, and generate content-planning suggestions for the owner.

Storage and security

  • All data is stored locally in a database on the owner's personal computer. It is not uploaded to any server operated by the app.
  • OAuth tokens are stored on that computer and encrypted with the Windows Data Protection API.
  • Data is kept until the owner deletes it.

Sharing

The app does not sell, share, rent or transfer any user data to third parties, and does not use it for advertising. Data is exchanged only with the official APIs listed above in order to retrieve it.

Google API Services

ChaosAnalytics' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube data is accessed via YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Google access can be revoked at any time at myaccount.google.com/permissions. Instagram access can be removed in Instagram under Settings → Website permissions → Apps and websites.
